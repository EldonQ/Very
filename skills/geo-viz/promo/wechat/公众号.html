1 每个做地理数据的人，都被中国地图折磨过

如果你做遥感、生态、地理、环境、气候、土壤这些方向，大概率遇到过这个场景：手里有一份栅格数据（GeoTIFF）——年均温、降水、NDVI、土地利用、人口密度……你想把它画成一张能进论文或组会 PPT 的中国地图。

听起来简单，真做起来却要过五关斩六将：

投影五花八门，Albers、Lambert、WGS84 混着来，先得重投影
要按中国边界裁剪，不然全球数据糊成一片
配色既要好看又要色盲友好，随手一个 jet 彩虹色会被审稿人吐槽
最容易翻车——必须画南海九段线、加南海诸岛小地图，否则地图不合规，轻则被打回，重则出版事故
最后还得导出高分辨率、透明背景的图，方便排版

一张图折腾大半天，换个变量又要重来一遍。于是我把这一整套流程沉淀成了一个开源工具：geo-viz。

2 一行命令，全自动出图

geo-viz 的目标只有一个：让你把精力放在数据和科学问题上，而不是画图的体力活。你只需要一行命令，把栅格数据丢进去：

python render_china_map.py \
  --input data.tif --output out/temp \
  --title "Annual Mean Temperature" \
  --legend "degC" --palette temp --clamp

它会自动完成：

① 重投影到统一地理坐标系（EPSG:4326）

② 按中国边界掩膜，只保留中国范围数据

③ 套用按变量类型语义化的 Nature 级色盲友好配色

④ 叠加省界 + 南海九段线，右下角自动生成南海诸岛小地图

⑤ 2–98 分位截断处理离群值，避免色带被极端值"洗白"

⑥ 导出 600 dpi 透明 PNG + 矢量 PDF，论文 PPT 直接用

3 连续数据、分类数据都能画

连续场（温度、降水、生物量、坡度、人口……）自动上渐变色带；离散分类（土地覆盖等）自动出分类图例。内置 CLCD 9 类、Global LULC 6 类、Harmonised 8 类等地类配色，一条命令：

python render_china_map.py \
  --input landcover.tif --output out/lc \
  --mode class --classes clcd \
  --title "Land Cover" --legend "Class"

内置 20 多套语义化配色，按变量类型直接选：温度用 temp、降水用 precip、植被用 veg、高程用 terrain、人口用 pop、土壤 pH 用 ph……不用再纠结调色。

4 R 和 Python 双引擎，参数完全一致

这大概是最贴心的一点：同一套命令行参数，R 和 Python 两个版本都能跑，出图版式一致。

Python 版基于 rasterio / geopandas / matplotlib；R 版基于 terra / sf / ggplot2。你的项目用什么语言，就用哪个版本，团队协作也不用互相迁就。

Rscript render_china_map.R \
  --input data.tif --output out/temp \
  --title "Annual Mean Temperature" \
  --legend "degC" --palette temp --clamp
